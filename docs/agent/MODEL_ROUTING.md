# 모델 라우팅

| 허용 설정 | 역할 |
| --- | --- |
| GPT-6.1 Sol Extra High (`gpt-6.1-sol`, `xhigh`) | 기본: 구조 탐색, 문서, Graft, 설치, 로컬 서버, 일반 수정, 정적 검증, Git |
| GPT-6.1 Sol Max (`gpt-6.1-sol`, `max`) | 위험·불확실성이 높은 작업의 검토와 해결 |

다른 모델로 임의 변경하거나 위임하지 않는다. Max는 별도 모델 이름이 아니라 같은 모델의 추론 강도 설정이다. 공식 지원 값은 [OpenAI 모델 문서](https://developers.openai.com/api/docs/models/gpt-6.1-sol)를 확인한다.

## 승격 판단

- **Max 필수 검토 대상:** 인증·보안 변경, 개인정보·고객 데이터 처리, DB 마이그레이션, 운영 구성 변경. Max 사용 여부와 별개로 운영 작업에는 명시적 승인이 필요하다.
- **Max 권장:** 대규모 아키텍처 변경, 복잡한 빌드·런타임 장애, 여러 시스템에 걸친 의존성 변경, 고위험 플랫폼 호환성 수정, 원인 불명의 중대한 장애.
- 문서 작성이나 단순한 Windows 셸 문법 수정만으로 Max를 요구하지 않는다.

이 Markdown은 모델 설정을 강제하거나 실행 중인 채팅의 추론 강도를 바꾸는 프로그램이 아니다. 자동 전환 도구가 없으면 승격 필요성과 미지원 상태를 기록하고 안전한 독립 작업을 계속한다. 필수 검토가 필요한 고위험 변경은 해당 검토와 필요한 사용자 승인까지 보류한다. 확인할 수 없는 현재 추론 강도를 검증했다고 주장하지 않는다.
