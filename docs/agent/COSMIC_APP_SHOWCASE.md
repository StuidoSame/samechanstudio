# Icon-first Cosmic App Showcase — 2026-10-30

판정: **COSMIC_APP_SHOWCASE_VISUALLY_VERIFIED** — Windows 실제 브라우저에서 같은 앱·같은 크기의 전후 화면과 전환 중 프레임을 비교했다. 이전의 행성/아이콘 밀착 구도와 일대일 분리 구도를 대체한다.

## 변경된 시각 구조

앱마다 구체·대기·고리·그림자와 작은 아이콘을 배치하던 구조가 시선을 분산시켰다. 카드에서는 행성 레이어를 모두 제거하고 원본 아이콘 프레임 하나만 남겼다. 같은 X/Y/Z 원근 궤적을 공유하며 중앙은 확대, 양옆은 약한 Y 회전과 깊이·명암으로 구분한다. 두 객체의 별도 위치·float·아이콘 보조 tilt도 제거했다. 기존 spring과 pointer 처리만 사용한다.

아주 어두운 보라색 배경·성운·별·얇은 별자리를 유지하고 중복 궤도·diamond 장식은 Hero에서 숨겼다. 공통 행성은 왼쪽 위와 오른쪽 아래 가장자리에 고정되며 앱 선택과 관계없다. 기존 `cosmic-planets/moon.svg`, `gas.svg`만 참조하고 실제 우주 자산·기존 7종 재질 파일·생성기는 삭제하지 않았다. 추가 라이브러리·Canvas·WebGL·프레임 루프·타이머가 없다.

앱 정보는 중앙 아이콘 아래에 정렬했다. 데스크톱 화살표는 캐러셀 높이, 모바일 화살표는 재생 컨트롤 행에 맞췄다. 가장자리 앱은 투명도를 부드럽게 보간해 등장·이탈하며 정착 상태는 중앙과 양옆 3개 아이콘이다. 글자 크기·다국어·스토어 URL·원본 아이콘·상세 데이터는 보존했다.
