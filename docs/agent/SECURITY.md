# 보안과 변경 안전

- `.env` 파일의 내용, API 키, 토큰, 쿠키, 인증 헤더, 사용자 입력·고객 데이터는 로그·문서·커밋에 기록하지 않는다. 환경변수는 이름과 목적만 문서화한다.
- 실제 비밀정보·운영 API·결제·인증·개인정보 처리·DB schema를 환경 구축에 섞지 않는다. 배포 명령과 Cloudflare 운영 리소스 변경은 명시적 요청 전까지 실행하지 않는다.
- 사용자 데이터 삭제, 권한 변경, 예상 밖의 대규모 삭제, 데이터 손실이나 노출 가능성이 있는 작업은 안전 중단하고 구체적 영향을 설명한다.
- 사용자 변경의 자동 stash/reset/clean을 하지 않는다. 검증 로그는 ignored `outputs/`에 저장하고 공유 전에 비밀 값·개인정보 포함 여부를 점검한다.
- 운영 계정·실제 메일 발송·계정 삭제를 smoke test로 사용하지 않는다. 현재 delete-account UI는 mailto 요청 작성이며 삭제 완료를 검증하는 서버 API가 아니다.
- 의존성의 install/postinstall과 네이티브 실행 파일을 설치 전 확인한다. 출처가 불명확한 동명 Graft 패키지를 설치하지 않는다. `npm audit fix --force`로 의존성을 자동 교체하지 않는다.
- 로컬 서버를 loopback에 유지하고 필요 없는 LAN 노출·포트 개방을 하지 않는다. 다른 프로젝트의 Node/Android/Docker 프로세스를 종료하지 않는다.

현재 npm audit 결과는 이미 존재하는 의존성 위험을 나타낸다. 경고 발견과 실제 악용 가능성 판단은 구분하고, 보안 개선은 영향 분석과 [MODEL_ROUTING](MODEL_ROUTING.md)의 Max 검토를 통해 별도 변경으로 수행한다. 공개 사이트 응답만으로 운영 환경의 비밀 설정이나 배포 revision을 추정하지 않는다.
