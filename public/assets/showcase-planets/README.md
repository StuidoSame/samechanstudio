# App showcase materials

Original deterministic SVG surfaces generated by `node scripts/generate-showcase-planets.mjs`. No external photographs, textures or app icon pixels are used.

Each 384px asset fixes its surface relief, spherical limb shading and upper-left light in one image. Mapary uses terrain, Pulto flowing gas bands, EVRUNE dark clouds, TOCOBI restrained strata, SKKOO fine matte dust, Teru Bozu bright clouds and WAESSEUM projected craters. Existing catalog IDs are intentionally retained in filenames.

These assets belong only to the home app showcase. Cosmic intro assets are independent. CSS supplies the atmosphere and front/back rings; icons remain separate original images. SVG filters are static image rasterization, with no embedded scripts, animation or external references.
