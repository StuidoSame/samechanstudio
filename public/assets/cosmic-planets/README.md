# Cosmic intro planet materials

These six SVGs are original procedural artwork generated by
`scripts/generate-cosmic-planets.mjs` in this repository. They do not contain
downloaded photographs, third-party textures, scripts, fonts, or external URLs.
No third-party image attribution or texture license is required; the project's
own licensing applies. They depict fictional bodies rather than named planets.

Regenerate from the repository root on Windows or macOS:

```text
node scripts/generate-cosmic-planets.mjs
```

Seeds, projected crater positions, gas bands, ice fissures, relief, and the
upper-left lighting are deterministic. SVG intrinsic sizes are 384px for rocky
and gas, 256px for atmosphere and ice, 160px for moon, and 128px for distant.
The browser renders each SVG as a CSS background image; the app animates only
its containing plane's transform and opacity. No JavaScript rendering loop or
WebGL context is required. Image cache memory remains browser-managed.
